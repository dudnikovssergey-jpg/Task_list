# Task_list
Данный проект позволяет вам формировать список задач, которые нужно выполнить.

## Возможности
- Добавлять задачи
- Удалять задачи
- Изменять задачи
- Задавать приоритет задач
- Отмечать задачи выполненными

## Инструменты
- html
- js
- css
## Структура проекта
```
Task_list/
├── index.html            - главная
├── js/
│    └── script.js        - форма  
├── css/
```
