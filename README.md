# Task_list
Данный проект позволяет вам формировать список задач, которые нужно выполнить.

## Возможности
- Добавлять задачи
- Удалять задачи
- Изменять задачи
- Задавать приоритет задач
- Отмечать задачи выполненными

## Инструменты
- html
- js
- css
## Структура проекта
Данный проект состоит из главной страницы, на которой отображаются кнопки: удаление, изменение, дабавление, отметка о выполнении и приоритетность задач. Файлы проекта лежат в папке public. В ней находятся: HTML-страница, офрмление проекта в style.css, форма в script.js.  В  App.js находится исходный код сервера, а в файле package.json хранятся задачи пользователя.
Task_list/
├── index.html              - главная
├── js/
│    └── script.js          - форма  
├── css/
│    └── style.css          - оформление
├── js/
│    └── App.js             - сервер
├── json/   
    └── package.json        - данные пользователя
